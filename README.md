# 💰 Expense Tracker - Budget Guardian

A simple Python app that helps you track your spending and stay within budget!

### 🚀 What it does
- Asks for your total budget
- Tracks 3 items you bought
- Calculates total spending
- Warns you if you're over budget or saves if you're under!

### 🛠️ How to run it
1. Open in Python / Pydroid
2. Run `Expense_tracker.py`
3. Enter your budget and items
